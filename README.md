# Меню беларускай кухні

Старонка з традыцыйнымі беларускімі стравамі і рэцэптамі: хлеб і выпечка, пірагі, струцаль, «зайцаў хлеб» і інш.

## Змест
- Катэгорыі страў з карткамі.
- Кароткія апісанні і рэцэпты.

## Тэхналогіі
HTML + CSS + JavaScript (адна старонка `index.html`).

## Запуск
Статычны сайт — адкрый `index.html` або GitHub Pages.
